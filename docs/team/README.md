# Team Directory

This directory contains team structure, roles, and a roster template for the MITA DAO Platform project.

Purpose:
- Capture roles and responsibilities required to run deployments, maintain CI/CD, and operate the platform.
- Provide contact and escalation templates for the short run.

Files:
- `roles.md` — short descriptions of recommended roles and responsibilities.
- `roster_template.md` — a template to collect names, contact details, timezones, and responsibilities.

How to use:
- Project leads should populate `roster_template.md` with actual team members.
- Use `roles.md` to map people to roles for sprints and incident rotations.
